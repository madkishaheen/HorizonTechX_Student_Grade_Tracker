# HorizonTechX Student Grade Tracker

A professional Java Swing GUI application for managing and analyzing student academic performance.

## 📌 Project Overview

The **HorizonTechX Student Grade Tracker** allows users to enter student details and subject marks, calculate academic performance, and generate a detailed grade report.

The application is developed using **Java Swing** and follows basic **Object-Oriented Programming (OOP)** concepts.

## ✨ Features

- Enter student name
- Enter 10-digit student ID
- Enter marks for multiple subjects
- Validate marks between 0 and 100
- Calculate total marks
- Calculate average marks
- Find highest score
- Find lowest score
- Automatically calculate grade
- Display performance message
- Professional graphical user interface
- Clear entered information
- Exit application safely
